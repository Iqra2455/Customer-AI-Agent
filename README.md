 # 🤖 AI Customer Support Agent

A lightweight, responsive, and intelligent AI Customer Support Agent built with **Python**, **Streamlit**, and powered by **Google Gemini API** (`gemini-2.5-flash`). 

This project was developed as part of the **Google Gen AI Academy** Codelab Track 1.

---

## ✨ Features
* 💬 **Interactive Chat UI:** Clean and modern ChatGPT-like interface built with Streamlit's native chat components.
* ⚡ **Fast & Intelligent Responses:** Powered by Google's `gemini-2.5-flash` model for instant customer query resolution.
* 📜 **Session Chat History:** Maintains conversation history during active sessions.
* 🔒 **Secure Environment:** Built with secure API key management using `.env` for local setup and Streamlit Secrets for cloud deployment.

---

## 🛠️ Tech Stack
* **Language:** Python 3.13
* **Frontend/Backend Framework:** Streamlit
* **AI Model API:** Google GenAI SDK (`google-genai` / Gemini 2.5 Flash)
* **Deployment:** Streamlit Community Cloud
